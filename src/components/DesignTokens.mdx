# Design Tokens

FlexPrice uses Tailwind CSS for its design tokens, defined in `tailwind.config.js` and `src/index.css`. This page documents the core foundations of our visual language.

## Colors

Our color system maps to functional roles using `hsl` CSS variables, allowing for seamless dark mode support.

## Border Radius

We use a standard base radius of `6px` across the application to maintain a sharp, professional B2B SaaS feel.

## CSS Variables

We use standard Shadcn/UI variable mapping in `index.css`:
```css
:root {
  --background: #f8fafc;
  --foreground: 0 0% 3.9%;
  --card: 0 0% 100%;
  --card-foreground: 0 0% 3.9%;
  --primary: 0 0% 9%;
  --primary-foreground: 0 0% 98%;
  --muted: 0 0% 96.1%;
  --muted-foreground: '#64748B';
  --border: 0 0% 89.8%;
  --radius: 6px;
}
```
